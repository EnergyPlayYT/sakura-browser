# Hintergrundbilder der Startseite

Alle Bilder in diesem Ordner (.jpg, .jpeg, .png, .webp) zeigt die Sakura-Startseite
als Hintergrund – auf dem PC und in der Android-App. Sie wechseln automatisch
(Standard: jede Minute) mit einem weichen Übergang.

Neue Bilder hinzufügen: auf GitHub in diesen Ordner gehen → „Add file“ →
„Upload files“ → Bilder hineinziehen → „Commit changes“. Danach baut GitHub
automatisch eine neue Sakura-Version.

Tipp: Bilder im Querformat, etwa 1920 × 1080 Pixel und unter 1 MB je Bild.
